# SZZBench Generated Repository Viewer

This tool is a local Web viewer for repositories generated by SZZBench.

Unlike the `scenario.yml` state viewer, this viewer reads the **actual generated Git repository** under `generated-input-repos/` and uses Git commands through a local Node.js backend.

## What it shows

- Generated repository list
- Scenario metadata
- Logical commit ID to actual Git hash mapping
- Commit timeline
- Files at each selected commit
- File content at the selected commit
- Diff from the selected commit's parent
- `git blame` output for a selected file
- Bug oracle from `metadata/scenario.yml`
- `verify-result.json`, if available

## Requirements

- Node.js
- npm
- Git available on `PATH`

## Usage

From the SZZBench repository root:

```bash
cd tools/generated-repo-viewer
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:5174
```

The backend API runs on:

```text
http://127.0.0.1:4174
```

## Expected generated repository layout

The viewer expects generated repositories like this:

```text
generated-input-repos/
  SZZ-0006/
    default/
      repo/
        .git/
        ...
      metadata/
        scenario.yml
        commit-map.json
        verify-result.json
```

## Notes

This viewer does not modify repositories. It only reads generated repositories and metadata.
